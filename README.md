README для проекта 🚀 Космического шутера на PyGame ⭐️
Описание проекта 📖
Проект представляет собой простейший космический шутер, созданный с использованием библиотеки PyGame. Цель игры — управлять космическим кораблем, уничтожать пришельцев и избегать их попадания в нижнюю часть экрана.

Игрок управляет своим кораблем с помощью клавиш стрелок вправо-влево (← и →), стреляя по пришельцам кнопкой пробела (Spacebar). Если корабль сталкивается с противником или враг достигает нижней границы экрана, игра заканчивается 😱. После завершения игрок может начать новую игру нажатием клавиши R ✨.

Установка и запуск приложения 🔧
Требования:
Python версии 3.7+ 👌
Библиотека PyGame 🛠️
Инструкция установки:
Установите необходимые зависимости:

pip install pygame
Скачайте файлы с изображениями и звуковыми эффектами:
spaceship: изображение космического корабля (rocket.png) 🚀
enemy: изображение противника (ufo.png) 🛸
background: фоновое изображение космоса (galaxy.jpg) 🌌
bullet: изображение снаряда (bullet.png) 💣
music: музыкальное сопровождение (space.ogg, fire.ogg) 🎶
Файлы лучше разместить рядом с основным файлом .py.

Запустите основной файл игры командой:

python main.py
Основные элементы игры 🎮
Игровое поле: экран размером 800×600 пикселей 🖥️
Корабль игрока: управляется горизонтально стрелками клавиатуры, стрельба осуществляется пробелом 🗡️
Противники: случайное количество UFO появляется сверху и движется вниз 🦁
Стрельба: снарядами уничтожаются вражеские корабли 💥
Звуковое оформление: звуки стрельбы и фоновая музыка (опционально) 🔊
Управление игрой 🕹️
Клавиша	Действие
←	Движение влево
→	Движение вправо
Space	Стрельба
Esc	Выход
R	Перезагрузить игру
