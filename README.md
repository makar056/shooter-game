# 🚀 Космический шутер на PyGame  

## ⭐️ Описание проекта  
📖 Проект представляет собой простейший космический шутер, созданный с использованием библиотеки **PyGame**.  
🔫 **Цель игры** — управлять космическим кораблем, уничтожать пришельцев и не допускать их попадания в нижнюю часть экрана.  

🎮 **Игровой процесс:**  
- Управление кораблём: **←** (влево) и **→** (вправо).  
- Стрельба: **Spacebar** (пробел).  
- Поражение: если враги достигают низа экрана или сталкиваются с игроком.  
- Рестарт: клавиша **R** после проигрыша.

## 🔧 Установка и запуск  

### 📋 Требования:  
- **Python 3.7+**  
- **Библиотека PyGame**  

### ⚙️ Инструкция по установке:  
1. Установите зависимости:  
   ```bash
   pip install pygame
   ```  
2. Скачайте игровые ассеты:  
   - 🚀 Корабль: `rocket.png`  
   - 🛸 Враги: `ufo.png`  
   - 🌌 Фон: `galaxy.jpg`  
   - 💣 Снаряд: `bullet.png`  
   - 🎶 Звуки: `space.ogg` (фоновая музыка), `fire.ogg` (выстрел)  
3. Запустите игру:  
   ```bash
   python main.py
   ```

## 🎮 Основные элементы игры  
| Элемент         | Описание                                  |  
|-----------------|-------------------------------------------|  
| 🖥️ **Игровое поле** | Экран 800×600 пикселей                    |  
| 🚀 **Корабль**      | Управляется стрелками, стреляет пробелом  |  
| 👾 **Враги**        | UFO, движутся вниз                        |  
| 💥 **Стрельба**     | Уничтожение врагов снарядами              |  
| 🔊 **Звуки**        | Фоновая музыка и звук выстрела (опционально) |

## 🕹️ Управление  
| Клавиша   | Действие               |  
|-----------|------------------------|  
| **←**     | Движение влево         |  
| **→**     | Движение вправо        |  
| **Space** | Огонь                  |  
| **Esc**   | Выход из игры          |  
| **R**     | Рестарт после поражения|
